**Neon Orbit** — a tiny neon arcade browser game built by an AI agent from a single prompt. Fly a spaceship through a starfield, steer with mouse or arrow keys / WASD, collect glowing stars for points, dodge tumbling asteroids, survive on 3 lives while the speed ramps up — and chase the high score.

## Run it

```sh
open index.html
```

No build step, no dependencies: just open `index.html` in any desktop browser (or serve the folder with any static server, e.g. `python3 -m http.server`).
