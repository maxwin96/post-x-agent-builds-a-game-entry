# THE ONE PROMPT

> Build a tiny neon arcade browser game called "Neon Orbit": a small spaceship
> flies in a starfield, the player steers with mouse or arrow keys / WASD,
> collects glowing stars for points, dodges tumbling asteroids, has 3 lives,
> difficulty ramps up over time, shows score and lives on a HUD, and ends with
> a game-over screen and restart button — all in one self-contained index.html
> with no external assets.

The game in this repo (`index.html`) was built from exactly this one prompt.
